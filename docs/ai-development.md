# AI development notes

I used Code0 for three tasks while testing the project:

1. **Application testing:** Checking the app’s main workflows.
2. **MongoDB setup:** Working through connection instructions and database configuration.
3. **API testing:** Testing requests and checking Express API responses.

## Project checks

The repository includes automated tests for CRUD, MongoDB persistence, input validation, search, and request error handling. Run them with `pnpm test`. The production build and formatting checks are available through `pnpm build` and `pnpm format:check`.
